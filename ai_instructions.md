## 6. Multi-Platform Competitive Research & Analysis Protocol (SEO, AEO & GEO)

Never optimize or write content in an internal vacuum. Lalani Computers must dominate modern search engines and AI generative models across enterprise IT hardware in India:

### 1. Traditional SEO (Search Engine Optimization)
- **Semantic Hierarchy:** Single `<h1>` per route, proper `<h2>`/`<h3>` nested hierarchy.
- **Server-Side Rendering (SSR/SSG):** All core copy, specification tables, and link hubs must be server-rendered for crawlability.
- **Internal Link Equity:** Hub-and-spoke architecture linking solution pages (`/solutions/*`) to relevant product categories (`/products/*`) and vice versa. Every product and solution page must feature clear contextual pathways (e.g., Enterprise Servers ↔ Colocation ↔ IT Asset Buyback).
- **Canonical & Meta Hygiene:** Every page must specify an accurate self-referencing canonical URL and high-converting, keyword-targeted OpenGraph meta tags.

### 2. AEO (Answer Engine Optimization)
- **Direct Answer Blocks:** 40–60 word declarative definitions immediately following primary informational questions (e.g., *"What is the lead time for custom enterprise server delivery in Mumbai?"*, *"How does corporate IT asset buyback work?"*).
- **FAQ Schema:** Implement comprehensive `FAQPage` JSON-LD schemas targeting exact high-intent queries asked by corporate IT managers.

### 3. GEO (Generative Engine Optimization for LLMs)
- **Structured Specification Tables:** Use HTML `<table>` elements with clear headers for hardware specs, server configurations, SLA response tiers, and buyback valuation criteria. LLMs (Perplexity, SearchGPT, Claude, Gemini) heavily prioritize structured tables for citations.
- **Knowledge Graph Entity Linking:** Anchor Lalani Computers as an authoritative local entity linked to Mumbai IT hardware distribution, Fort business district, and genuine OEM supply.

## 7. The 3-Pillar Value Extraction Filter

Every proposed feature, layout tweak, or content block must pass through all three pillars:

### Pillar 1: UX First & Mobile-Desktop Parity
- **Mobile First-Class Citizen:** On mobile phones, screens have limited vertical real estate. Eliminate clutter (e.g., hide redundant eyebrow pills when necessary, wrap contextual links into clean tappable badges, ensure video overlays maintain high text contrast).
- **Desktop Grandeur:** On desktop/laptop displays, maintain rich, two-row structured navigation, elegant bulleted separators, full-fidelity hover states, and smooth Framer Motion micro-interactions.
- **Frictionless Conversion:** Direct WhatsApp links (`https://wa.me/919323332850?text=...`) must include context-aware pre-filled messages specifying the product or solution the user was viewing.

### Pillar 2: Commercial & Transactional Alignment
- Every page must have clear commercial bridges. For example:
  - When an IT head views `/products/servers` or `/solutions/data-center`, they are likely retiring old racks — provide an **IT Asset Buyback** bridge.
  - When viewing `/solutions/office-setup`, provide bridges to **Network Hardware**, **AMC Support**, and **Workstations**.

### Pillar 3: Code Cleanliness & Zero Regressions
- **Do Not Touch Unrelated Code:** Never alter, rename, or rewrite existing working components or routes unless explicitly instructed.
- **TypeScript Integrity:** All props and state must be strictly typed without sloppy `any` types.
- **Zero Console Errors:** Clean hydration, no nested `<a>` inside `<Link>`, no missing keys in loops.

## 8. The "Don't Just Delete — Pivot" Protocol

When a feature or section doesn't work as expected on a specific device:
1. **Diagnose Device Context:** Differentiate between mobile phone constraints and desktop ergonomics.
2. **Pivot Responsively:** Instead of completely deleting a feature from the whole website, make it responsive (e.g., `hidden sm:inline-flex` to hide on phones while preserving desktop perfection; or switching dense inline text to touch-friendly pill badges on mobile).
3. **Preserve Business Value:** Never sacrifice SEO anchor text or conversion funnels during aesthetic cleanups.
